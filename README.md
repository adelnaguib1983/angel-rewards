# Faith Tracker Rewards

انشاء تطبيق مخصص للبنين لمتابعة عدة أشياء يقوموا بها علي مدار اليوم والاسبوع وفي مقابل تحقيق ذلك يتم مكافئتهم ببونص أو هدايا داخل التطبيق ومن هذه الأشياء المراد متابعتها حضور القداس في الاسبوع الاول من الشهر أو الاسبوع الثاني أو الاسبوع الثالث أو الاسبوع الرابع وايضا حضور الخدمة بنفس النظام وايضا التناول وايضا الاعتراف وأيضا قراءة الانجيل وايضا أكثر اية لمست قلبك وايضا العطا في اسابيع الشهر بالوان واشكال تجذب انتباه البنين.

مع المتطلبات التالية:
- عند إرسال التطبيق إلى المستخدمين والتسجيل فيه، لا يتم تفعيل الحساب أو السماح بالدخول إلا بعد موافقة المشرف (لوحة تحكم لإدارة واعتماد طلبات التسجيل).
- عند تسجيل أو إدخال البيانات والأنشطة من قبل المستخدمين، يتم إشعار المشرف بذلك لمتابعتهم أولاً بأول.
